# talachiyan.github.io

سایت شخصی مهندس حسین طلاچیان — https://talachiyan.github.io/

- `index.html`: صفحهٔ اول (معرفی و میان‌بر به بخش‌ها)
- `services.html`، `approach.html`، `articles.html`، `contact.html`: صفحه‌های منو
- `style.css`: رنگ‌ها و سبک سایت (متغیرهای بالای فایل)
- `favicon.svg`: نشان سایت

سایت ثابت است و نیاز به ساخت (build) ندارد؛ GitHub Pages مستقیم از شاخهٔ `main` منتشرش می‌کند.
